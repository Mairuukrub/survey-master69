# แบบสัมภาษณ์ชุมชน · ฝึกภาคสนามร่วม ศวส. มข. ครั้งที่ 44 (2569)

เว็บแอปแบบสัมภาษณ์ครัวเรือน (ถอดจาก `แบบสอบถามเขต 8 COMMED 69.docx` 13 ส่วน) ใช้ได้บนมือถือ แท็บเล็ต และคอม
บันทึกในเครื่องได้แม้ไม่มีสัญญาณ แล้วส่งเข้า **Google Sheets** เมื่อมีอินเทอร์เน็ต

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | ตัวเว็บแอป |
| `questions.js` | แบบสอบถามฉบับตั้งต้น (commed69) คำถาม ตัวเลือก และเงื่อนไขการข้ามข้อ |
| `form_core.js` | เลือกฉบับที่ใช้ (ฉบับที่ผู้ดูแลเผยแพร่ → ฉบับตั้งต้น), ตัวตรวจเงื่อนไข, คอลัมน์, ตรวจความถูกต้อง |
| `analysis.js` | ชุดข้อมูลพร้อมวิเคราะห์: ตัวแปรคำนวณ (ใช้ร่วมกับหน้าวิเคราะห์), รหัสสูญหาย, ชุดไม่ระบุตัวตน, Codebook, syntax SPSS/Stata/R |
| `admin.html`, `admin.js`, `admin.css` | หน้าผู้ดูแล แก้ไขแบบสอบถามเองโดยไม่ต้องแก้โค้ด |
| `sw.js`, `manifest.webmanifest` | ให้เปิดใช้ได้แบบออฟไลน์ และเพิ่มไว้หน้าจอโฮมได้ |
| `apps_script/Code.gs` | ตัวรับข้อมูลที่วางใน Google Apps Script |

## ตั้งค่า Google Sheets (หัวหน้าทีมทำครั้งเดียว ~5 นาที)
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก `apps_script/Code.gs` แล้วตั้งรหัส (ตั้งเองให้เดายาก เช่น `ทีม-คำลับ-ตัวเลข` ยาว 6 ตัวขึ้นไป ห้ามซ้ำกัน)
   | รหัส | ใครใช้ | ทำอะไรได้ |
   |---|---|---|
   | `TEAM_CODE` | นักศึกษาทุกคน | ส่งข้อมูล · โหลดแบบสอบถาม — **อ่านข้อมูลที่ส่งแล้วไม่ได้** |
   | `READ_CODE` | หัวหน้าทีม / อาจารย์ | เปิดหน้าวิเคราะห์ · ดาวน์โหลดข้อมูล |
   | `ADMIN_CODE` | ผู้แก้แบบสอบถาม | ทุกอย่าง (ไม่ต้องตั้งถ้าไม่แก้แบบสอบถาม) |
3. **Deploy → New deployment →** ชนิด **Web app** · Execute as **Me** · Who has access **Anyone** → Deploy → อนุญาตสิทธิ์
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิดเว็บแอป → **ตั้งค่า** → วาง URL + รหัสทีม → **ทดสอบการเชื่อมต่อ**

> แก้โค้ด Apps Script ภายหลัง: Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy (URL เดิมใช้ต่อได้)
>
> **อัปเกรดจากเวอร์ชันก่อน (v3):** วาง `Code.gs` ใหม่ทั้งไฟล์ (คัดลอกรหัสเดิมกลับมาใส่) ตั้ง `READ_CODE` แล้ว Deploy เป็น New version — หน้าวิเคราะห์จะถามรหัสดูผลแทนรหัสทีม ระหว่างที่ยังไม่อัปเดต Apps Script หน้าวิเคราะห์จะบอกว่าเป็นเวอร์ชันเก่า ส่วนแบบฟอร์มของนักศึกษาส่งข้อมูลได้ตามปกติ

> **อัปเกรดเป็น v4 (ตรวจบ้านข้ามเครื่อง):** วาง `Code.gs` ใหม่ทั้งไฟล์ (คัดลอก `TEAM_CODE` `READ_CODE` `ADMIN_CODE` เดิมกลับมาใส่) แล้ว Deploy → Manage deployments → แก้ไข → Version: New version → Deploy (URL เดิมใช้ต่อได้) ถ้ายังไม่อัปเดต แอปจะบอกใต้ช่องบ้านเลขที่ว่า “Apps Script ยังเป็นเวอร์ชันเก่า” และใช้งานต่อได้ตามปกติ

## ฉบับ commed69 (เขต 8 COMMED 69)
- ตรงกับ `แบบสอบถามเขต 8 COMMED 69.docx`: ตัดส่วนที่ 8 สุขภาพจิตใจ (PHQ-2) และข้อ 4.2.4 ดื่มจนเมา ส่วนที่ 9–14 เดิมเลื่อนเป็นส่วนที่ 8–13
- ตาราง 9.3–9.15 แก้เลขข้อที่ซ้ำในฉบับเดิม (10.12/10.13 ชุดที่สอง → 9.14/9.15) ข้อควบคุมอาหารเป็น 9.16 และ 9.17
- เอาชุดคำถามเพิ่มเติม v2 ออกทั้งหมด (ส่วนที่ 15–18, โมดูล 2.2 เกษตรกร, 2.3 พนักงานโรงงาน, 3.8 เบาหวาน, 3.9 ความดัน และอาชีพรหัส 8 ลูกจ้าง/พนักงานโรงงาน)
- **รหัสข้อ (ชื่อคอลัมน์) ยังเป็นของ Master69** เช่น ข้อ 8.1 แพ้ยา คือคอลัมน์ `q9_1` ข้อ 13.2.1 คือ `q14_2_1` เพื่อไม่ให้คอลัมน์เดียวกันใน Sheet มีความหมายสองแบบ ดูเลขข้อตามกระดาษได้ใน Codebook (`form_version` บอกว่าแถวไหนตอบด้วยฉบับใด)

## ผู้ดูแลแก้ไขแบบสอบถามเอง (admin.html)
ตั้งค่าครั้งเดียว: ใน Apps Script ตั้ง `ADMIN_CODE` (ยาว 6 ตัวขึ้นไป ไม่ซ้ำรหัสทีม ให้เฉพาะผู้ดูแล) → Deploy → Manage deployments → แก้ไข → Version: **New version** → Deploy

1. เปิด `admin.html` → ใส่ URL ของ Apps Script และรหัสผู้ดูแล → **เชื่อมต่อ**
2. เลือกฉบับที่จะแก้ (ฉบับที่ใช้อยู่ / ฉบับตั้งต้น / ไฟล์ JSON / เวอร์ชันเก่าจากประวัติ)
3. แก้ส่วน คำถาม ตัวเลือก ตาราง และ **เงื่อนไขการแสดง** (เช่น แสดงเมื่อข้อ 3.1 เลือก “เบาหวาน”) — บันทึกเป็นร่างในเครื่องอัตโนมัติ
4. **ทดลองใช้** = เปิดแบบฟอร์มด้วยฉบับร่าง (`index.html?preview=1`) ข้อมูลทดลองไม่ถูกส่งและไม่ปนกับข้อมูลจริง
5. ตรวจรายการปัญหา/ส่วนต่างจากฉบับเดิม → ตั้งชื่อเวอร์ชันใหม่ → **เผยแพร่ให้ทุกเครื่อง**

กติกาที่ระบบบังคับเพื่อไม่ให้ข้อมูลเก่าเพี้ยน: ข้อที่เคยใช้แล้วเปลี่ยนรหัสข้อและชนิดไม่ได้ · รหัสตัวเลือกไม่เปลี่ยนเมื่อเลื่อนลำดับ ตัวเลือกใหม่ได้รหัสถัดไปเสมอ ·
เผยแพร่ซ้ำชื่อเวอร์ชันเดิมไม่ได้ (ทุกเวอร์ชันเก็บในชีต `forms` ย้อนกลับได้โดยโหลดจากประวัติแล้วเผยแพร่เป็นเวอร์ชันใหม่)

เครื่องนักศึกษาจะได้ฉบับใหม่เมื่อเปิดแอปตอนมีอินเทอร์เน็ต (มีแถบ “มีแบบสอบถามเวอร์ชันใหม่ — โหลดใหม่”) คำตอบที่กรอกค้างไว้ไม่หาย
หน้าวิเคราะห์ใช้ฉบับล่าสุดเสมอ และมีส่วน “สรุปรายข้อ (อัตโนมัติ)” ทำกราฟให้ทุกข้อที่เป็นตัวเลือก/ตัวเลข รวมข้อที่ผู้ดูแลเพิ่มเอง

## การใช้งานของนักศึกษา
มีหน้า **วิธีใช้** ในแอป (ปุ่มมุมขวาบน) สรุปทุกข้อด้านล่างพร้อมสถานะของเครื่อง ให้นักศึกษาอ่านก่อนลงพื้นที่
ระหว่างกรอกมีแถบล่างติดจอ (ก่อนหน้า · ชื่อส่วนและจำนวนที่ตอบ — แตะเพื่อไปข้อที่ยังไม่ตอบ · ถัดไป) · **ตั้งค่า → การแสดงผล** เลือกธีมสว่าง/มืด และขยายตัวอักษรได้ (กลางแดดแนะนำธีมสว่าง)
1. เปิดลิงก์เว็บแอป → **ตั้งค่า** ใส่ URL และรหัสทีม (ครั้งแรกครั้งเดียว) → เพิ่มไว้หน้าจอโฮม
2. **สัมภาษณ์ครัวเรือนใหม่** → กรอกทีละส่วน (ข้อที่ต้องข้ามจะหายไปเอง, อายุและ BMI คำนวณให้)
   - ใต้ช่องบ้านเลขที่ (ถ้ามีสัญญาณ) แอปถาม Google Sheets ว่าบ้านนี้ **ส่งเข้าระบบแล้วกี่ชุด** แสดงเพศ อายุ วันที่ และผู้สัมภาษณ์ของแต่ละชุด กับจำนวนรวมทั้งหมู่บ้าน ถ้าไม่มีสัญญาณจะบอกว่าตรวจไม่ได้ ไม่ขัดการกรอก · เห็นเฉพาะชุดที่ **ส่งแล้ว** ของทุกเครื่อง (ชุดที่ยังค้างส่งในเครื่องอื่นยังมองไม่เห็น จึงควรส่งข้อมูลทุกคืน)
   - ใต้ข้อวันเกิด: ถ้า **เพศ + วัน/เดือน/ปีเกิดครบ** ตรงกับชุดในระบบของบ้านเดียวกัน ขึ้นข้อความสีเหลืองว่าน่าจะเป็นคนเดียวกัน (เซิร์ฟเวอร์เทียบให้ ไม่ส่งวันเกิดของใครกลับมา) ถ้าตรงแค่เพศ + อายุ ขึ้นข้อความเตือนเบากว่า (ไม่บังคับ)
   - **คำตอบระดับครอบครัว:** ข้อรายได้ครอบครัว (1.8), หนี้สิน (1.9 และจำนวนหนี้), สัตว์เลี้ยง (10.1–10.4), วิธีจัดการขยะ (11.1.1–11.1.2) และสารเคมีเกษตร (11.3.1, 11.3.1.1) ถ้าคนอื่นในบ้านเดียวกันตอบไว้แล้ว (ในเครื่องนี้หรือใน Sheet) จะมีกล่อง “ครอบครัวนี้เคยตอบไว้: … [ใช้ค่านี้]” ใต้ข้อ และปุ่ม “ใช้ทั้งหมดในส่วนนี้” เป็นข้อเสนอเท่านั้น ผู้สัมภาษณ์ต้องถามผู้ตอบยืนยันและกดเอง · ไม่เสนอคำตอบที่เป็นความคิดเห็น/ประสบการณ์ส่วนตัวหรือข้อมูลสุขภาพ · ใช้ได้เมื่อบ้านมีเลขที่เท่านั้น · คอลัมน์ `fam_from` (uuid ของชุดต้นทาง) และ `fam_q` (ข้อที่ใช้คำตอบนั้นและยังไม่ถูกแก้) บันทึกที่มาไว้ใน Sheet
   - หน้าแรกแสดงความคืบหน้าทั้งทีม (จำนวนคนและบ้านที่ส่งแล้ว ไม่นับ MOCK) ค่าล่าสุดค้างไว้ได้เมื่อออฟไลน์
   - ข้อความสีเหลืองใต้ข้อ = ค่าที่ควรตรวจอีกครั้ง เช่น ส่วนสูงที่กรอกเป็นเมตร ปีเกิดเป็น ค.ศ. บ้านเลขที่ซ้ำกับที่มีในเครื่อง (ไม่บังคับ บันทึกได้)
3. หน้าสุดท้าย **ตรวจทานและส่ง** → ทุกข้อที่ยังไม่ตอบ/ควรตรวจกดไปที่ข้อนั้นได้ → บันทึก (ส่งทีหลัง) หรือ บันทึกและส่งเลย
4. ไม่มีสัญญาณก็สัมภาษณ์ต่อได้ ข้อมูลอยู่ในเครื่อง พอมีสัญญาณกด **ส่งข้อมูลที่ค้าง** (หรือระบบส่งให้เองเมื่อกลับมาออนไลน์)
5. แก้คำตอบหลังส่งได้ จะส่งซ้ำไปแก้แถวเดิมใน Sheet (ไม่เกิดแถวซ้ำ)

**สำคัญ:** อย่าล้างข้อมูลเบราว์เซอร์/ใช้โหมดไม่ระบุตัวตน ก่อนส่งข้อมูลครบ · กด **ดาวน์โหลดสำรอง (CSV)** เก็บไว้เป็นระยะ (หน้าแรกจะเตือนเมื่อมีข้อมูลค้างแต่ยังไม่ได้สำรองเกิน 1 วัน)

เวลาสัมภาษณ์บันทึกให้เอง: `started_at` = ตอนกรอกคำตอบแรก · `finished_at` = ตอนกดบันทึกในหน้าตรวจทานครั้งแรก · `duration_min` = ส่วนต่าง (นาที)

## ข้อมูลใน Google Sheets
- 1 แถว = 1 ครัวเรือน · แถวแรกเป็นชื่อคอลัมน์ตามเลขข้อ เช่น `q4_1`
- ข้อเลือกข้อเดียว = รหัสตัวเลข (ดูความหมายใน **Codebook** ที่ดาวน์โหลดได้จากหน้าแรก)
- ข้อตอบได้หลายข้อ = 1 คอลัมน์ต่อ 1 ตัวเลือก (`q3_1_o1` = เบาหวาน, 1 = เลือก, 0 = ไม่เลือก)
- "ระบุ" = คอลัมน์ `..._o<รหัส>_text` · ข้อที่ถูกข้ามตามเงื่อนไขจะเป็นช่องว่าง
- เลขข้อที่ซ้ำในเอกสารต้นฉบับถูกแยกรหัสให้ไม่ชนกัน (เช่น ข้อ 5 "แยกกันอยู่" = 5, ข้อ 10.12/10.13 ชุดที่สอง = `q10_12b`, `q10_13b`)

## หน้าวิเคราะห์ (dashboard.html)
เปิด `dashboard.html` → ใส่ URL ของ Apps Script และ **รหัสดูผล** (`READ_CODE` ไม่ใช่รหัสทีม) จะดึงข้อมูลจาก Sheet สดทุกครั้งที่เปิด
รหัสจำไว้เฉพาะแท็บนั้น เว้นแต่เลือก “จำรหัสไว้ในเครื่องนี้” · ปุ่ม **ออก** ลบรหัสออกจากเครื่อง
สรุปทุกส่วนของแบบสอบถามเป็นกราฟ กรองตามหมู่ เพศ กลุ่มอายุได้ และมีตารางคุณภาพข้อมูล: รายผู้สัมภาษณ์ (ตอบครบ, เวลาสัมภาษณ์, จำนวนที่สั้นกว่า 10 นาที), บ้านที่ถูกสัมภาษณ์ซ้ำข้ามเครื่อง, รายวัน
ถ้าไม่ได้ตั้งค่า เปิดไฟล์ CSV ที่ดาวน์โหลดจาก Sheet แทนได้

## ข้อมูลสำหรับวิเคราะห์ (SPSS / Stata / R / Excel)
หน้าวิเคราะห์ → **ดาวน์โหลดข้อมูลสำหรับวิเคราะห์** ได้ 5 ไฟล์ที่ใช้คู่กัน (ไม่รวมแถว MOCK): ข้อมูล CSV · Codebook · `.sps` · `.do` · `.R`
วางไว้โฟลเดอร์เดียวกันแล้วเปิดไฟล์ syntax ของโปรแกรมที่ใช้ จะได้ชื่อตัวแปร ชื่อคำตอบ และรหัสสูญหายครบ
- **ไม่ระบุตัวตน (แนะนำสำหรับส่งต่อ)** ตัดบ้านเลขที่ ชื่อหมู่บ้าน วันเดือนปีเกิด (เหลืออายุ) ชื่อผู้สัมภาษณ์ และข้อความอิสระทั้งหมด ใช้ `pid` / `iv_id` แทน (คำนวณจากรหัสทีม จึงเหมือนเดิมทุกครั้งที่ดาวน์โหลด และย้อนกลับไม่ได้)
- **ข้อมูลเต็ม** ใช้ภายในทีมเท่านั้น
- ช่องตัวเลขที่ว่างใน Sheet ถูกแยกเป็น `-1` = ข้ามตามเงื่อนไขของแบบสอบถาม และ `-9` = ควรถามแต่ไม่ได้ตอบ (ตั้งเป็น missing ให้แล้วในทุกโปรแกรม)
- ตัวแปรคำนวณต่อท้าย: `age_grp` `age_60plus` `bmi_cat` (เกณฑ์เอเชีย) `obese` `ncd_any` `ncd_n` `smoke_cur` `alcohol_cur` `no_exercise` `msk_pain` `farmer` — นิยามเดียวกับตัวเลขบนหน้าวิเคราะห์ (แก้ที่ `analysis.js` ที่เดียว)
- ข้อมูลใน Google Sheet ไม่ถูกเปลี่ยน (ยังเป็นช่องว่างเหมือนเดิม) รหัสเหล่านี้สร้างตอนดาวน์โหลด

## ข้อมูลจำลองสำหรับทดสอบ
`index.html?mock=120&api=<URL>&team=<รหัส>` สร้างครัวเรือนจำลอง 120 หลัง (record_id ขึ้นต้นด้วย `MOCK`) ส่งเข้า Sheet
ไม่เก็บในเครื่อง · หน้าวิเคราะห์ซ่อน/แสดงข้อมูลจำลองได้ · **ลบแถว MOCK ใน Sheet ก่อนเก็บข้อมูลจริง**

## ความเป็นส่วนตัว (PDPA)
ข้อมูลมีบ้านเลขที่ วันเกิด และโรคประจำตัว จึงเป็นข้อมูลสุขภาพส่วนบุคคล
- แชร์ Google Sheet เฉพาะผู้ที่ต้องใช้ (ปิด "ทุกคนที่มีลิงก์") · ห้ามเผยแพร่ไฟล์ข้อมูลดิบ
- URL ของ Apps Script ไม่พอจะอ่านข้อมูล · รหัสทีมส่งข้อมูลได้อย่างเดียว อ่านข้อมูลที่ส่งแล้วไม่ได้ · ข้อมูลดิบเปิดได้ด้วย `READ_CODE` หรือ `ADMIN_CODE` เท่านั้น ให้เฉพาะคนที่ต้องใช้
- รหัสดูผลส่งใน POST body ไม่อยู่ใน URL (ไม่ค้างในประวัติเบราว์เซอร์) · การใส่รหัสผิดถูกบันทึกในชีต `log`
- รหัสทีมเรียก `action: house` ได้ ซึ่งคืนเฉพาะเพศ อายุ วันที่ ผู้สัมภาษณ์ ของบ้านที่ถาม และจำนวนรวม และ (เมื่อขอ) **คำตอบระดับครอบครัวตามรายการ `FAMILY_COLS` ใน `Code.gs` เท่านั้น** (รายได้ หนี้สิน สัตว์เลี้ยง การจัดการขยะ สารเคมีเกษตร) ไม่คืนชื่อผู้ตอบ วันเกิด คำตอบด้านสุขภาพ หรือความคิดเห็น ไม่นับแถว MOCK และแถวที่ใส่ `1` ในคอลัมน์ `exclude` · ข้อมูลรายได้และหนี้สินจึงอ่านได้ด้วยรหัสทีม (อาจารย์เห็นชอบแล้ว) เลขบ้านส่งใน POST body ไม่อยู่ใน URL
- ส่งต่อข้อมูลให้ผู้วิเคราะห์ด้วยชุด **ไม่ระบุตัวตน** จากหน้าวิเคราะห์
- เว็บแอป (ไฟล์ในโฟลเดอร์นี้) ไม่มีข้อมูลผู้ตอบ นำขึ้นเว็บสาธารณะได้

## ทดสอบระบบ
เปิด `index.html?selftest=1` จะกรอกคำตอบสุ่ม 25 ครัวเรือน ตรวจการข้ามข้อ/คอลัมน์ แล้วแสดงผลท้ายหน้า
(เติม `&api=<URL>&team=<รหัส>` เพื่อทดสอบส่งจริง — ข้อมูลทดสอบจะเข้า Sheet ให้ลบทิ้งหลังทดสอบ · โหมดนี้ล้างข้อมูลในเครื่องก่อนเริ่ม ห้ามใช้บนเครื่องที่มีข้อมูลจริง)
