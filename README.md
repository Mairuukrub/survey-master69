# แบบสัมภาษณ์ชุมชน · ฝึกภาคสนามร่วม ศวส. มข. ครั้งที่ 44 (2569)

เว็บแอปแบบสัมภาษณ์ครัวเรือน (ถอดจาก `แบบสอบถามเขต_Master69.docx` ครบ 14 ส่วน) ใช้ได้บนมือถือ แท็บเล็ต และคอม
บันทึกในเครื่องได้แม้ไม่มีสัญญาณ แล้วส่งเข้า **Google Sheets** เมื่อมีอินเทอร์เน็ต

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | ตัวเว็บแอป |
| `questions.js` | คำถาม ตัวเลือก และเงื่อนไขการข้ามข้อ (แก้คำถามที่ไฟล์นี้ไฟล์เดียว) |
| `sw.js`, `manifest.webmanifest` | ให้เปิดใช้ได้แบบออฟไลน์ และเพิ่มไว้หน้าจอโฮมได้ |
| `apps_script/Code.gs` | ตัวรับข้อมูลที่วางใน Google Apps Script |

## ตั้งค่า Google Sheets (หัวหน้าทีมทำครั้งเดียว ~5 นาที)
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก `apps_script/Code.gs` แล้วเปลี่ยน `TEAM_CODE` เป็นรหัสของทีม (ตั้งเองให้เดายาก เช่น `ทีม-คำลับ-ตัวเลข`)
3. **Deploy → New deployment →** ชนิด **Web app** · Execute as **Me** · Who has access **Anyone** → Deploy → อนุญาตสิทธิ์
4. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. เปิดเว็บแอป → **ตั้งค่า** → วาง URL + รหัสทีม → **ทดสอบการเชื่อมต่อ**

> แก้โค้ด Apps Script ภายหลัง: Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy (URL เดิมใช้ต่อได้)

## การใช้งานของนักศึกษา
1. เปิดลิงก์เว็บแอป → **ตั้งค่า** ใส่ URL และรหัสทีม (ครั้งแรกครั้งเดียว)
2. **สัมภาษณ์ครัวเรือนใหม่** → กรอกทีละส่วน (ข้อที่ต้องข้ามจะหายไปเอง, อายุและ BMI คำนวณให้)
3. หน้าสุดท้าย **ตรวจทานและส่ง** → บันทึก (ส่งทีหลัง) หรือ บันทึกและส่งเลย
4. ไม่มีสัญญาณก็สัมภาษณ์ต่อได้ ข้อมูลอยู่ในเครื่อง พอมีสัญญาณกด **ส่งข้อมูลที่ค้าง** (หรือระบบส่งให้เองเมื่อกลับมาออนไลน์)
5. แก้คำตอบหลังส่งได้ จะส่งซ้ำไปแก้แถวเดิมใน Sheet (ไม่เกิดแถวซ้ำ)

**สำคัญ:** อย่าล้างข้อมูลเบราว์เซอร์/ใช้โหมดไม่ระบุตัวตน ก่อนส่งข้อมูลครบ · กด **ดาวน์โหลดสำรอง (CSV)** เก็บไว้เป็นระยะ

## ข้อมูลใน Google Sheets
- 1 แถว = 1 ครัวเรือน · แถวแรกเป็นชื่อคอลัมน์ตามเลขข้อ เช่น `q4_1`
- ข้อเลือกข้อเดียว = รหัสตัวเลข (ดูความหมายใน **Codebook** ที่ดาวน์โหลดได้จากหน้าแรก)
- ข้อตอบได้หลายข้อ = 1 คอลัมน์ต่อ 1 ตัวเลือก (`q3_1_o1` = เบาหวาน, 1 = เลือก, 0 = ไม่เลือก)
- "ระบุ" = คอลัมน์ `..._o<รหัส>_text` · ข้อที่ถูกข้ามตามเงื่อนไขจะเป็นช่องว่าง
- เลขข้อที่ซ้ำในเอกสารต้นฉบับถูกแยกรหัสให้ไม่ชนกัน (เช่น ข้อ 5 "แยกกันอยู่" = 5, ข้อ 10.12/10.13 ชุดที่สอง = `q10_12b`, `q10_13b`)

## หน้าวิเคราะห์ (dashboard.html)
เปิด `dashboard.html` (ใช้ URL และรหัสทีมชุดเดียวกับแบบฟอร์ม) จะดึงข้อมูลจาก Sheet สดทุกครั้งที่เปิด
สรุปทุกส่วนของแบบสอบถามเป็นกราฟ กรองตามหมู่ เพศ กลุ่มอายุได้ และมีตารางคุณภาพข้อมูลรายผู้สัมภาษณ์/รายวัน
ถ้าไม่ได้ตั้งค่า เปิดไฟล์ CSV ที่ดาวน์โหลดจาก Sheet แทนได้

## ข้อมูลจำลองสำหรับทดสอบ
`index.html?mock=120&api=<URL>&team=<รหัส>` สร้างครัวเรือนจำลอง 120 หลัง (record_id ขึ้นต้นด้วย `MOCK`) ส่งเข้า Sheet
ไม่เก็บในเครื่อง · หน้าวิเคราะห์ซ่อน/แสดงข้อมูลจำลองได้ · **ลบแถว MOCK ใน Sheet ก่อนเก็บข้อมูลจริง**

## ความเป็นส่วนตัว (PDPA)
ข้อมูลมีบ้านเลขที่ วันเกิด และโรคประจำตัว จึงเป็นข้อมูลสุขภาพส่วนบุคคล
- แชร์ Google Sheet เฉพาะผู้ที่ต้องใช้ (ปิด "ทุกคนที่มีลิงก์") · ห้ามเผยแพร่ไฟล์ข้อมูลดิบ
- URL ของ Apps Script ไม่พอจะอ่านข้อมูล และจะบันทึกเฉพาะเมื่อรหัสทีมถูก แต่ไม่ควรโพสต์รหัสทีมในที่สาธารณะ
- เว็บแอป (ไฟล์ในโฟลเดอร์นี้) ไม่มีข้อมูลผู้ตอบ นำขึ้นเว็บสาธารณะได้

## ทดสอบระบบ
เปิด `index.html?selftest=1` จะกรอกคำตอบสุ่ม 25 ครัวเรือน ตรวจการข้ามข้อ/คอลัมน์ แล้วแสดงผลท้ายหน้า
(เติม `&api=<URL>&team=<รหัส>` เพื่อทดสอบส่งจริง — ข้อมูลทดสอบจะเข้า Sheet ให้ลบทิ้งหลังทดสอบ · โหมดนี้ล้างข้อมูลในเครื่องก่อนเริ่ม ห้ามใช้บนเครื่องที่มีข้อมูลจริง)
